# ⚙ Create — планировщик конвейерных линий

Одностраничный сайт для проектирования построек из мода **Create** (Minecraft)
с симуляцией конвейерных линий: предметы видны **на входе и на выходе каждой ступени**.

## Как открыть

- **С любого устройства** — после выкладки на хостинг (GitHub Pages) просто по ссылке в браузере.
- **Локально** — двойной клик по `index.html`, интернет не нужен: всё в одном файле
  (HTML + CSS + JS, без внешних зависимостей и сборки).

## Возможности

- **30 блоков Create**: конвейер, воронки, жёлобы, разделитель, эжектор,
  дробилка, пресс, миксер, мельница, механический крафтер, пила, бур,
  деплойер, вентилятор (обжиг/промывка/удушье), трубы, насос, резервуар, сопло,
  валы и шестерни, паровой двигатель, водяное колесо, креативный и электромотор,
  сундуки-источники/приёмники, утилизатор.
- **Симуляция**: предметы и жидкости движутся по лентам, ступени перерабатывают
  их по рецептам (упрощённые рецепты Create), на выходе каждой ступени — свой предмет.
- **Рецепты**: готовый список для каждого блока + свой рецепт
  (1–2 входа, жидкость, выход, время).
- **Энергия**: расчёт Stress Units по сетям (нагрузка/ёмкость/RPM,
  перегрузка останавливает сеть), галочка «Автопитание».
- **Фильтры** для воронок и разделителя, разделение потоков по выходам.
- **Вкладка «Линия»**: таблица всех ступеней — вход → выход, очередь,
  счётчики, итоги производства и сети питания.
- **Импорт/экспорт**: JSON-проект, PNG-схема, автосохранение в браузере.
- **Пример линии** кнопкой «🏠 Пример линии».

## Управление

| Клавиша | Действие |
|---|---|
| `V` | выделение |
| `B` | рисование ленты (направление по движению мыши) |
| `C` | установка блока из палитры |
| `E` | ластик |
| `H` | панорама (или средняя кнопка мыши) |
| `R` | поворот блока |
| `Del` | удалить блок |
| `Пробел` | пуск/пауза симуляции |
| колесо мыши | масштаб |

Рецепты упрощены для удобства планирования и могут отличаться от игры.
